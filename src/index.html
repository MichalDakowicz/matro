Connect over SSH

Read media from your server. Files stay on the server; playback runs on this PC.

Uses SSH key authentication and your known hosts. First connect successfully in a terminal with ssh username@server. The server needs Python 3 and FFmpeg for embedded text subtitles. Password prompts are not supported inside Matro.

Connect to a Matro server

Watch a library hosted on your own Matro server. You sign in on the server's page; the address is the only thing saved here.

Matro then opens the server in this window. Its menu (Alt) has Use local library and Disconnect from server. Start with MATRO_LOCAL=1 to open the local library once.
