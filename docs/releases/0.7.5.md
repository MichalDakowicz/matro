Matro 0.7.5 fixes intermittent **Failed to fetch** errors during browser and desktop receiver playback. Routine progress saves no longer compete for the browser's small keepalive quota, and automatic skip markers stay on the server instead of being sent back with every save.

Automatic detection now keeps one main intro and outro per episode, removes stray recap suggestions after the opening, and preserves manual marks. Existing server and desktop detections are corrected when loaded, without rescanning the library.

The server fixes are deployed. Refresh an existing browser or receiver window to load the updated web app.

This release updates Windows desktop. Android 0.7.4 already receives the corrected markers from the server and needs no new APK: [existing Android download](https://github.com/MichalDakowicz/matro/releases/tag/v0.7.4).

Windows includes an installer and SHA-256 checksum. Regression checks cover slow overlapping progress saves, marker selection and persisted desktop markers, playback recovery, and the server API. Remote playback smoothness still depends on the connection and media preparation; the fetch-error regression verifies progress saving rather than end-to-end playback on a remote Wi-Fi network.
