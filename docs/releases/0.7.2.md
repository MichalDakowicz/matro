# Matro 0.7.2

Fixes the duplicate top bars and fullscreen regression in desktop receiver mode.

- Removes the native Windows title bar and application menu bar. Receiver mode uses Matro's floating window controls, matching the local player.
- Fullscreen uses Electron's native window state. The player button and F toggle fullscreen; Escape exits without leaving the movie. Matro's floating controls hide while fullscreen.
- The Server button opens Playback source in both modes, including on the server sign-in screen. Choose Use this PC to return to the local library.
- An unavailable saved server shows reconnect/settings controls rather than leaving an empty window.
- The receiver's remote page receives only restricted window/source controls, with no local library, file or settings-write access.

Updates Windows desktop and the server-served web UI. Android remains on 0.7.0. Verification includes a real receiver/server UI test covering frame/menu removal, source settings before sign-in, restricted bridge access, fullscreen layout, the fullscreen button, F and Escape.
