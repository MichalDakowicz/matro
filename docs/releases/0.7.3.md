Matro saves playback position as the video advances, without touching the seek bar. Rewatching a completed title now starts a new resumable session. The browser and desktop commit a durable local checkpoint and restore the newest saved position when reopening, even if the server missed the save.

Server playback now compares episodes of the same show and season to find intro, recap and outro ranges. In **Skip segments**, you can mark a range by hand, apply manual marks to the season, or remove a suggestion for your account. Android shows the skip button when a saved range is playing.
