# Matro 0.7.1

Desktop patch: restores a visible way to choose between the local library and a Matro server.

- The **Server** button beside Matro opens Playback source. Enter the server address, choose **Use server**, and sign in on the server screen.
- The app remembers the selected source and server address across launches. Local library files and progress are preserved when switching.
- Receiver mode exposes **Playback source → Server settings…** and **Playback source → This PC** in the native menu, including on the sign-in screen.
- When a saved server is unavailable, settings remain accessible for reconnecting or returning to the local library.
- Remote pages retain their isolated browser environment and do not receive local file or settings privileges.
- A quick buffered seek immediately after startup now replaces the startup resume target before saving, preserving the seek position when leaving straight away.

Includes regression checks for source persistence, address validation, remote-page isolation, local progress preservation, and unavailable-server recovery. Android and the server remain on 0.7.0; this release updates the Windows desktop app.
